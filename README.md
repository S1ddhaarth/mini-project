# Full Stack Open Course Solutions

This repository contains my solutions to the exercises from the Full Stack Open course.

## Structure

The solutions are organized by course parts:

- Part 0: Fundamentals of Web apps
- Part 1: Introduction to React
- Part 2: Communicating with server
- Part 3: Programming a server with NodeJS and Express
- Part 4: Testing Express servers, user administration

## Course Information

Full Stack Open is a modern web development course by the University of Helsinki.

Course website: https://fullstackopen.com
